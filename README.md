# LawnCare

A web app for tracking lawn care activities, inspired by Carfax CarCare.

## Getting Started

1. Install dependencies: `npm install`

2. Run the development server: `npm run dev`

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- Dashboard for lawn health

- Track watering, mowing, fertilizing

- Equipment shed for maintenance

## Tech Stack

- Next.js

- TypeScript

- Tailwind CSS

- Supabase (for database and auth)
